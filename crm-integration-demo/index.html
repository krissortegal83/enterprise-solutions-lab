ENGINEERING TRADEOFFS

What happens in production?

◇

Identity & deduplication

Normalize email addresses before matching. Production systems may need an external master ID and merge-review queues.

⟳

Idempotency & retries

Identical events produce no duplicate writes. A real integration additionally needs durable event IDs, retries and rate-limit handling.

⚑

Conflict transparency

Stale updates are rejected; equal-time conflicting changes are flagged for human review rather than silently overwriting data.

This is a browser simulation backed by a separate Python reference implementation. It does not connect to Zoho, HubSpot, KMOV or customer systems.
