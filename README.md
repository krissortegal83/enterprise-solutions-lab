## Cómo está organizado

## Mi enfoque

Entender la operación, definir reglas claras, probar los errores y preparar una buena entrega. Mi experiencia combina tecnología hospitalaria, implementaciones empresariales, atención a clientes y colaboración con especialistas.

## Para revisar el código

```bash
python -m http.server 8000
# Abre http://localhost:8000
node scripts/check-site.mjs
node --test tests/*.test.mjs customer-success-intelligence/tests/*.test.mjs
python -m unittest discover -s tests -v
```

Usa Node.js 22 o posterior y Python 3.11 o posterior. No necesitas instalar paquetes para las demos del catálogo. [Pruebas y alcance](docs/QUALITY.md).

## Sobre los ejemplos

Son proyectos independientes, creados con ayuda de IA y datos ficticios. No representan trabajos de antiguos empleadores ni resultados de clientes. Las conexiones con sistemas reales están fuera del alcance de estas demos. La documentación de cada caso explica qué hace y qué faltaría para usarlo en una operación real.
